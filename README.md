# AI Music Detector

Frontend for the thesis "Web-Based AI-Generated Music Detection Using MFCC and Random Forest Among First-Year PUP Students" (PUP Quezon City, BSIT).

Static site: open `index.html`. No build step.

The classifier in `js/app.js` is a placeholder trained on synthetic clips so the UI can be demoed. The real Random Forest model and backend come later.
